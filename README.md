# 🌿 InAmigos Foundation — Official Website

> **"Together We Build a Kinder, Greener India"**

A responsive, single-page website built for **InAmigos Foundation**, 
a Section 8 NGO founded in 2020, headquartered in Bilaspur, Chhattisgarh. 
The site showcases the foundation's mission, flagship projects, and 
impact across 28 Indian states.

🔗 **Live Demo:** [in-amigos1.vercel.app](https://in-amigos1.vercel.app)

---

## 🛠️ Tech Stack

- **HTML5** — Structure and content
- **CSS3** — Styling and responsive layout
- **JavaScript** — Interactivity
- **Vercel** — Deployment

---

## 📌 Features

- Smooth scroll navigation with anchor links
- Responsive design for mobile, tablet, and desktop
- Impact stats section (50K+ beneficiaries, 200+ volunteers, 28 states)
- Six flagship project cards: SEVA, Bachpanshala, JEEV, UDAAN, PRAKRITI, VIKAS
- Gallery section with real photos from field activities
- Donation and volunteer call-to-action buttons
- Contact and social media links in footer

## 🌍 About InAmigos Foundation

**Founded:** 23 September 2020  
**Founder:** Mr. Govind Shukla  
**Location:** Bilaspur, Chhattisgarh  
**Certifications:** ISO 9001:2015 | 80G & 12A | CSR-1 | NITI Aayog NGO Darpan

InAmigos Foundation works across six key social causes:

| Project | Focus Area |
|---|---|
| Project SEVA | Food & Clothing Distribution |
| Project Bachpanshala | Education for Underprivileged Children |
| Project JEEV | Animal Welfare |
| Project UDAAN | Women Empowerment |
| Project PRAKRITI | Environmental Conservation |
| Project VIKAS | Skill Development & Internships |
